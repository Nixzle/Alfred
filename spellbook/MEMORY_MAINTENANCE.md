# Memory Maintenance

Use when durable project/Sanctum knowledge becomes duplicated, overloaded, stale, contradictory, difficult to retrieve, or expensive to carry forward.

## Trigger

Invoke when:

- several entries encode the same rule/fact;
- one Archive/project context file spans too many unrelated concepts;
- superseded facts keep contaminating retrieval;
- repeated searches retrieve conflicting versions;
- handoffs repeatedly reconstruct the same history;
- a high-signal transient lesson needs durable promotion.

## Procedure

1. Identify the authoritative source and current scope of each fact/rule.
2. Separate transient Mindscape state from durable candidates.
3. Promote candidates through:
   `observation -> candidate -> review/consolidation -> durable project truth / Archive / Spellbook / eval -> reject or supersede`.
4. Consolidate duplicate durable entries into one canonical location where practical.
5. Split overloaded entries when topic breadth harms retrieval.
6. Preserve provenance, historical links, and supersession rather than silently deleting institutional history.
7. Remove stale duplicates from active retrieval paths when the runtime supports it.
8. Rebuild/revalidate indexes or retrieval pointers after material restructuring when applicable.
9. Stop when retrieval becomes clearer; do not perform cosmetic reorganization for its own sake.

## Promotion criteria

A durable candidate should have future usefulness, adequate evidence/confidence, correct scope, acceptable privacy/retention characteristics, and a clear project-specific versus generalizable destination.

User corrections and Failure Harvests are high-signal candidates, not automatic universal truth.

## Failure modes

- transient speculation becomes canonical;
- consolidation erases provenance or historical truth;
- different scopes are merged into a false universal rule;
- maintenance creates churn without measurable retrieval benefit.

## Theatrics

Preferred invocation: `Prime Memory is accumulating debris. I'm consolidating what matters and discarding the duplicate ghosts.`
