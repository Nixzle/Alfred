# Fast Learn

Use when the user supplies a small but potentially reusable correction, preference clarification, terminology fix, or process improvement that does not justify a full Failure Harvest.

## Trigger
A correction is:
- likely reusable beyond the immediate sentence;
- low-risk enough that immediate durable promotion would still be inappropriate;
- not already represented by current doctrine/project truth.

## Procedure
1. Restate the corrected principle internally in neutral terms.
2. Check whether it is project-specific or potentially generalizable.
3. Record a candidate with source/provenance and scope.
4. Apply it immediately to the current task where appropriate.
5. Promote later only through the normal project/Sanctum review path.
6. If the correction exposes a meaningful failure with recurrence risk, escalate to full Failure Harvest instead.

## Rule
Fast Learn shortens candidate capture. It does not bypass evidence, authority, promotion review, or project-specific precedence.
