# Tool Incubation

Use when a recurring task may benefit from a new temporary tool, helper, adapter, evaluator or automation that does not yet deserve canonical installation.

## Procedure
1. Define the narrow capability and acceptance contract.
2. Prefer existing tools and Salvage First before creating anything new.
3. Build or configure the candidate in a sandbox or isolated scope when practical.
4. Give it minimum authority, data and network access.
5. Define explicit expiry/cleanup and no implicit persistence.
6. Test against representative success/failure cases.
7. Record evidence, limitations, provenance and security/maintenance risk.
8. Promote through normal review only if repeated value exceeds coordination and risk cost.

## Rule
A temporary tool may prove useful without gaining permanent authority. Successful execution is evidence, not self-ratification.
