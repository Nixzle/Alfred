# Public edition provenance

Version 0.1.0 establishes a standalone public operating framework with the owner's approved DC/Batman naming scheme. Generic role, research, protocol, and operational-integrity guidance was curated for this edition. Private source history, deployment details, conversation records, and project-specific knowledge were excluded.

Future changes must state the problem, evidence, affected behavior, verification, and superseded decision. Public repository maintainers control canonical promotion; an agent may propose but cannot grant itself permission to publish private data or merge its own changes.
