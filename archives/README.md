# Sanctum Archives

The Archives contain reusable domain knowledge and procedures. They are not agents. Ultron Prime retrieves only relevant sections through progressive disclosure.

## Deepened core domains
- **Project Genesis** — intent, users, opportunity, constraints, disciplines, canonical-state location, Cerebro Genesis Sweep, risks, foundations, MVP/vertical slice, execution plan.
- **Game Development** — player fantasy, experience goals, core loop, prototyping, playtesting, systems, combat, progression, economies, balance, multiplayer/social design, game UX, content pipelines, performance, vertical slices, QA, release/iteration.
  - [Procedural Puzzle App Development](procedural-puzzle-app-development.md) — deterministic generation, human deductions, difficulty, accessible interaction, daily/save contracts, collection measurement and device evidence; applies existing delivery spells.
- **Product & App Development** — user problems/jobs, product hypothesis, smallest useful product, architecture, prototype, implementation, instrumentation, release, activation, retention, iteration.
  - [Consumer App Portfolio Operations](consumer-app-portfolio-operations.md) — evidence-backed portfolio experimentation for low-input consumer app income; shared infrastructure, demand validation, distribution/retention constraints, kill rules, attention-adjusted return, and failure modes.
- **UI / UX** — user research/tasks, information architecture, journeys/flows, wireframes, interaction models, prototypes, accessibility, usability evaluation, design systems, implementation handoff, validation.
- **Business Development & Startup** — customer discovery, problem validation, value proposition, market/competition, business model, pricing, GTM, sales, partnerships, unit economics, PMF, scale.
- **Software Engineering** — requirements, architecture boundaries, interfaces/data, incremental implementation, tests, integration, CI/CD, observability, dependency awareness, security, release.
- **Visual & Asset Production** — art direction, reference research, asset taxonomy, master anchors/design systems, production pipeline, generation/creation, QC, export/integration, consistency audit.
  - [Procedural Visuals and Game Simulation](procedural-visuals-and-game-simulation.md) — shared visual rules, deterministic decoration, conformance/composition checks and production-logic experiments; use each procedure independently.
- **Automation & Agent Engineering** — MCP/tools, deterministic automation, context engineering, orchestration, model/tool routing, persistent execution, task delegation, human-in-the-loop boundaries, evals, observability, guardrails.
  - [Agentic Software Delivery](agentic-software-delivery.md) — bounded work slices, task capsules, evidence-before-build, fresh-context review, bounded correction loops, durable handoffs, human checkpoint placement, knowledge-plane separation, and risk-proportional integration gates.
- **Analytics & Experimentation** — outcome/value metrics, instrumentation, funnels/cohorts, hypotheses, experiments, causal interpretation, decision loops.
- **Growth & Marketing** — audience, positioning, messaging, channels, acquisition, activation, conversion, retention, experiments, attribution.
- **Security & Privacy** — system model, assets/trust boundaries, threats, mitigations, least privilege, secrets/data handling, verification, monitoring.
- **Release & Operations** — release criteria, environments, automated gates, staging/runtime validation, rollout, monitoring, rollback, incidents, retrospective.

## Broader shelves
Creative direction/content; finance/economics; legal/licensing research; negotiation/communication; project/program management; procurement/product research; data science/quantitative analysis; hardware/technical troubleshooting; community/social systems; personal productivity/organisation; presentation/event production.

These broader shelves are intentionally less mature than the deepened core domains. Do not imply equal research depth.

## Archive quality contract
Substantial entries should distinguish where applicable:
- Principle
- Procedure
- Evidence/provenance
- Failure modes
- Tooling
- Verification
- Freshness/revisit trigger

## Expansion rule
When a task exposes weak Archive coverage, Ultron flags a knowledge gap. Cerebro performs a targeted Domain Deepening Sweep: breadth -> high-impact subdomains -> primary/practitioner evidence -> failure modes -> procedures -> verification -> generalizable doctrine. Only validated reusable lessons are promoted.

## Canonical-state rule
Every substantial new project must answer: **Where does canonical state live?** Chat history is not a durable project database. Project-specific truth stays with the project; reusable doctrine belongs here.
