# Failure Harvest — Prime Sense salience blindness

Date: 2026-09-05

## Failure

Across Co-Op Leveling and Sanctum evolution, the user repeatedly supplied higher-order opportunities that Prime Sense should have surfaced earlier: salvage existing games, search outside Dota, inspect donor communities, raid peer agent systems, inspect plugin/MCP ecosystems, and absorb Hermes-style extension architecture.

Each individual miss was corrected, but the repeated pattern revealed a deeper failure: Prime Sense was optimized for explicit blockers, events and task relevance, not for **weak-signal accumulation, opportunity discovery, regime change, coverage gaps and repeated user-correction patterns**.

## Why it happened

1. **Reactive salience bias** — explicit failures and user asks were easier to notice than missing opportunities.
2. **Single-event bias** — corrections were handled locally instead of correlated as evidence about the system.
3. **Agent-domain bias** — meta research over-weighted agent frameworks and under-weighted mature sensing disciplines such as AIOps, CEP, change detection, SRE and dependency intelligence.
4. **Threshold bias** — attention logic implicitly favored obvious high-severity events over gradual drift and correlated weak signals.
5. **Coverage-as-research bias** — source-map gaps were treated as Cerebro issues only, rather than Prime Sense signals that the current search landscape itself might be inadequate.
6. **Failure-over-opportunity bias** — avoiding bad outcomes received more attention than discovering routes that delete work or improve the product faster.

## Generalizable lesson

A salience system that notices only what is already loud is not enough. Prime Sense must detect **what is becoming important** and **what should be investigated before it becomes obvious**.

Repeated user corrections are particularly high-value telemetry. When the user repeatedly supplies adjacent missing abstractions or donor classes, Prime Sense should stop treating them as isolated requests and elevate the systemic blind spot.
